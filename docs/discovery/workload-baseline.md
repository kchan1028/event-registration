# Workload baseline

Use this sheet to measure what the current workflow costs, so a later pilot can be compared against it. The [success measures](../../product.md#success-measures) in product.md (for example, organizer time at least 30% lower and median check-in under 30 seconds) mean nothing without this baseline.

Event measured: Berkeley Omnium two-day road race and criterium weekend (estimates only, not yet measured)  
Period covered: _from planning start to reconciliation complete_  
Sources so far: [D01](interviews/D01.md), 2026-11-14, follow-ups 2026-11-15

## Rules

- Mark every number **measured** (timed, counted from records) or **estimate** (someone's recollection). The exit gate needs at least the organizer hours and check-in times to be measured or backed by records.
- Count per event. For a two-day weekend, record each day's check-in separately.
- Record ranges when people disagree, and note who gave each figure (by role).
- Do not copy rider names or contact details into this sheet.
