The Golden State classification-rules page was retrieved directly after the web reader failed; only category and classification rules were used, not linked rider start lists or results. The CBR homepage's schedule, VIP, and season headings mix years; the separately dated flyers identify the studied edition. Search snippets and PDF metadata can be stale or misleading. The current record does not establish which conflicting value an organizer would approve.

Do not import a schedule merely because its text can be extracted. Keep contradictory time/cap/date values unresolved, distinguish staging from starts, and seek source approval before creating an executable named template. Berkeley's category counts refer to our working fixture and are explicitly separated from the published source. Source documents can change; a hash establishes which downloaded PDF was inspected, not that it is complete, authoritative, or valid next season.
